How to run it

  • Open presenter.html on your laptop and press O to open the audience window; drag it to the projector and press F for full screen.
  • Arrow keys or Space move both windows together (same browser). The timer starts on the first advance.
  • Live demo: python -m smokesentry.app.server --data-root <demo data> --runs-root <runs>, open http://127.0.0.1:8000, pick split test, fire 20190930_FIRE_om-s-mobo-c, run temporal-gru-dinov2s-frozen-v1-T8-s2-20261123, detector det-yolo11s-dfire-figlib-s0-20261116, speed 200, play; then switch the run to encoder-dinov2s-frozen-s0-20261117 to show the tile grid.
